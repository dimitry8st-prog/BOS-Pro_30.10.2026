## Тестовая имитация

- `FixtureProvider` возвращает заранее собранный текст. Это проверка управления выполнением. Оценка качества модели не выполнялась.
- URL fixture остаётся `not_checked`. Сетевого запроса не было. Доступность ссылки в отчёте не называется доказательством истинности.
- Внешние оценка, резерв и факт равны `0.00 RUB`, потому что учебный внешний расход задан нулём. Стоимость модели `null`, статус `not_measured`.
- `access_check` равен `not_performed`. Вызов границы membership завершается отказом `membership_check_not_implemented`.
- Публикация всегда возвращает `publication_handler_absent` и `not_published`.
- Отказ поставщика включается флагом прогона `--provider refuse` или аргументом исполнителя, а не текстом источника.
- Каталог `var/dev-store` — файлы этой машины для разработки. Это не PostgreSQL и не общее хранилище.

## Не завершено

- Миграции PostgreSQL, RLS, серверная проверка membership и ролей, изоляция двух workspace.
- Интерфейс React и развёртывание. Зависимости React и Supabase не устанавливались, их версии не закреплены.
- Реальный модельный endpoint, живая проверка URL, бюджет на запуск и период.
- Канал публикации и обработчик внешней публикации.
- Состояние `waiting_approval` описано и в этот сценарий не входит.
- Лицензия, срок хранения реальных данных, один пользователь или совместная работа, размещение приложения.

Открытые решения перечислены в контракте. Они не блокируют учебный прогон и блокируют соответствующие реальные интеграции.
